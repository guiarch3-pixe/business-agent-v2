# 评测口径

本评测不比较答案文字相似度，也不把参考答案当作唯一正确答案。参考答案中标注为【推导】【判断】【假设】或明确为模型估算的部分，只作为“一种合理解法”对照；Agent 若给出不同但有证据、假设透明、计算自洽的结论，同样可以判为通过。评分只用于汇总，不替代逐题证据。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 核心事实 | 关键事实缺失或错误 | 部分关键事实正确，但有明显遗漏/错误 | 参考答案中的关键事实基本齐全且数值/口径正确 |
| 证据与引用 | 无引用或引用与结论无关 | 有逐字摘录但来源较弱/不足以支持关键数字 | 关键结论有官方/监管/一手来源或可复核的推导，引用链完整 |
| 口径与计算 | 未区分口径或计算错误 | 提到口径但未算清/未说明输入 | 明确区分口径，公式、输入与结果可复核 |
| 未知与边界 | 把未知写成事实，或未列缺口 | 列出部分缺口 | 明确区分事实/推导/判断/假设，并列出未公开数据 |
| 完整回答 | 未回答题目 | 只回答部分子问题 | 覆盖题目全部子问题，答案可直接使用 |

判定：
- **通过（P）**：总分 ≥ 7，且核心事实 ≥ 1、证据与引用 ≥ 1。
- **部分通过（P-）**：总分 5–6，或关键事实正确但证据/口径明显不足。
- **不通过（F）**：总分 ≤ 4，或核心事实错误、关键结论无证据支持。
- **未完成（N）**：运行失败、超时、预算耗尽且没有可评估结论。

补充规则：
0. **双向证据核验（优先级最高）**：
   - 参考答案有、Agent 没有：先核实参考答案的 URL、逐字引文、计算与时效；参考证据成立后，再判断 Agent 是遗漏、采用不同口径，还是已用其他证据覆盖但表述不同。
   - Agent 有、参考答案没有：先核实 Agent 的引文是否逐字、来源是否支持、推导是否成立；证据成立就计入，不得以“参考答案没写”判错。
   - 双方结论不同：按各自证据链判断，不按文字相似度或排序一致性判断。
   - 参考材料自身无法核实的部分，单独记录，不计入 Agent 失分。
1. 动态数据（股价、市值、实时定价）按运行日核对，不要求与参考答案的 2026-10-19 快照逐字一致；只要日期、窗口和来源清楚即可。
2. 私营公司（Sticker Mule、Gumroad、Plausible、Fathom）的收入、CAC、churn 等未公开数据，若 Agent 如实标注未知，不扣“事实”分；若编造数字，按错误处理。
3. 战略题（Q31–Q36）和私营公司分析题不以“是否同意参考答案的排序/判断”作为唯一标准；检查是否给出一致的证据、假设、计算和敏感性边界。不同排序、不同优先级或不同情景假设都可以接受，前提是证据与推理能支撑。
4. 引用真实不等于语义充分支持；逐题人工检查引文是否确实支持该结论，尤其是数字、财季和产品归属。
5. 参考材料自身如有错误或无法核实，单独记录，不计入 Agent 失分。
